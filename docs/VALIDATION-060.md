## 未確認事項

Windows x64上での実GUI表示、セットアップ・更新、タスクバーへの実埋め込みは未確認。UI検証は固定寸法のDOMモデルで、見た目の実スクリーンショット検証ではない。

Bilibiliの実際の失敗動画・全リスト保存・ログイン、Discordへの実接続・サムネイル表示は未確認。報告された「ある取り込み元リストの動画全体が埋め込みで再生できない」原因は、動画URLと実行環境の診断記録がないため断定していない。公式サイトの構造・配信・認証仕様が変われば追加修正が必要。

Discordの背景全体を強制する機能は実装せず、公開仕様にある画像欄と動画リンクを実装。ボタンは本人のアクティビティ画面に出ない仕様。

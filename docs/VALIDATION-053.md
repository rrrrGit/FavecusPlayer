# Favecus Player 0.5.3 検証記録

2026-09-20。親選択の検索ツリー、追加操作の配置、子リスト作成、次曲の所属階層表示を追加。

| 項目 | 確認内容 |
| --- | --- |
| 初期状態 | 通常の新規作成では最上位だけを表示し、親なしを選択。矢印で親子を開閉し、開閉後のキーボードフォーカスを保持 |
| 階層検索 | 一致リストの祖先を開き、無関係な最上位・兄弟も含めた構造を維持。一致箇所を紫色にし、選択欄だけをスクロール。検索欄のフォーカスと再生リストの位置は保持 |
| 複数一致・入力 | 上下ボタン・検索欄のEnterで巡回。日本語変換確定のEnterは結果移動に使わない。大文字小文字・全角英字を正規化。一致なしと検索解除も確認 |
| 親の選択 | 検索だけでは親を変更しない。名前を選んで作成すると、そのリストの子になる。検索解除では検索前の開閉を復元 |
| 子リスト作成 | ヘッダーの＋で現在の子・孫を親として初期選択。次の通常新規作成では親なしへリセット。全リスト画面では専用＋を非表示 |
| 移動と入れ子作成 | 自分自身・子孫を候補から除外。作成した親へ正しく移動。元の画面と作成画面の状態を保持 |
| 次曲の階層 | 例のEroGameSongs/ケロQ・枕/サクラノ刻と一致。現在閲覧中のリストではなく次曲の所有者と再生スコープを使う。共有・名前変更・終了・シャッフル解除を確認 |
| 追加ボタン | 4つの並び順を保持し、最終的なCSSを右寄せに変更 |
| 前版の回帰 | 曲変更後のフォーカスとスクロール、折りたたみ中の再生、展開操作、取り込み、保存、キュー、名称移行などを含む既存ケースを維持 |

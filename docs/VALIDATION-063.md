# 0.6.3 検証記録

作業日: 2026-09-27（日本時間）。Linux x86_64環境。

## 結果

- Node自動テスト251件成功。失敗・中止・スキップ0。
- JavaScript87ファイルの構文確認成功。
- 模擬Win32によるランチャー・タスクバーの確認成功。FFFF7003が符号なしのまま保存され、固有の説明を返すことを確認。
- 模擬Electronで、close時にview.webContentsがundefinedとなる状況を再現。参照切れ・二重破棄・Viewの取り残しが起きないことを確認。
- 曲終了・クラッシュ通知中に画面のナビゲーション、切り離し、closeを実行しないことを確認。
- 終了通知の重複、スキップ連打の集約、以前の読み込み完了・失敗の無視、保留中の停止、予期しない画面破棄からの復旧を確認。
- 最初の画面作成前のクラッシュ記録初期化、外部送信無効、runtime/logsへの保存先指定、ログの世代管理、起動失敗時にアプリを止めないことを確認。
- 保存・移行・アーカイブ・検索・キー操作など、既存機能の回帰テストを含む。

## 配布確認

梱包スクリプトは4種類のEXEのPE構造・版番号・ハッシュ、模擬Win32の起動入口、UI資源の整合性を検証した記録を要求する。最終結果はソースZIPのrelease-validation/completion.jsonと同フォルダーのログに保存する。ZIPのCRCと元ファイルとのSHA256一致も梱包時に確認する。

## 未確認事項

画像のFP-EXIT-FFFF7003はCrashpad未接続時の終了値であり、元のクラッシュ原因は画像だけでは確定できない。画面のライフサイクルに実在した不具合を修正したが、ユーザーのWindows環境で発生したネイティブクラッシュそのものは再現していない。完全解消とは断定しない。

Windows実機のGUI、実インストール・更新、実際のクラッシュダンプ生成、Bilibili・Discordとの実接続は未確認。今回のUI確認は静的検証と模擬DOMであり、視覚検証ではない。GitHub関連には変更を加えていない。

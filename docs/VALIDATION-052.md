# Favecus Player 0.5.2 検証記録

2026-09-20。子プレイリストの展開ボタンと、再生操作後にクリックし直すまで追従しない問題への修正。

## 再現と修正

0.5.1ではrendererのwindow.blurで一覧・操作欄全体をinertにしていた。動画のWebContentsへフォーカスが移るだけでもこの処理が動く。また、手動スクロールから1.5秒以内の明示的な再生操作まで追従を抑制していた。これら2件は旧コードで追加テストが失敗し、修正後に成功することを確認した。

| 項目 | 確認内容 |
| --- | --- |
| フォーカス移動 | 動画へ移った後も一覧の操作を無効化せず、追加クリックなしで次曲へ追従。ダイアログ表示中は背景の操作を無効化する |
| 前面状態 | 曲変更通知より前に実際のウィンドウの状態を通知。UI・動画へのフォーカス復帰で同期。実際の背面・最小化時は前面と誤判定しない |
| 明示的な再生 | 手動スクロール直後でも曲の再生ボタンから追従。手動操作中の自動曲送りは引き続き抑制 |
| ポインター解放 | フォーカス移動でpointerupを失っても保持判定を解除し、以後の追従が止まらない |
| 展開・折りたたみ | 右の矢印で子・孫をその場に表示。開閉で再生APIを呼ばず、選択リスト・現在曲・キューを維持。キーボードのフォーカスも保持 |
| 展開中の曲 | 所属する子リストの曲を編集・並べ替え。親の曲順は保持。展開中の曲を検索可能。全リスト再生の重複は既存キューへ解決 |

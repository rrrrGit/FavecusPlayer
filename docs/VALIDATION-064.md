# 0.6.4 検証記録

Linux x86_64環境で実施。

## 結果

- Node自動テスト257件成功。失敗・中止・スキップ0。
- JavaScript89ファイルの構文確認成功。
- 模擬Win32のランチャー・タスクバー確認成功。80000003の符号なし終了値と説明表示を含む。
- 前版のmain.cjsでは3種類の新しい競合テストがすべて失敗し、修正版ですべて成功。オンライン・ローカルの遅延読み込みと、画面側から開始するナビゲーションを対象にした。
- 読み込み途中のフォーカス、表示範囲変更、音量設定、再生切り替え、古い終了通知、停止で切り替え中のmainFrameを参照しない。準備後は最新の音量とモーダル中のキー制御を反映する。
- iframe・同一文書内の移動では不要に送信を止めない。レンダラー終了・破棄後の送信を拒否する。検索画面の音量と停止にも適用する。
- プレイリスト、保存・移行・アーカイブ、選択取り込み、シャッフル、キー操作、フォーカス・スクロール、画質・Discordデータ等の既存回帰テストを含む。

## 配布条件

梱包スクリプトは4種のEXEのPE構造・版・SHA256、模擬Win32の起動入口、UI資源・プロトコル許可リストの静的検証を要求する。これらの最終結果はソースZIPのrelease-validation/completion.jsonと同フォルダーのログへ同梱する。ZIPのCRCと元ファイルのハッシュも梱包時に確認する。

## ダンプ分析と限界

受領ダンプ8件の停止アドレスを一致する公式PDBで特定した。詳細とアプリ側の対策はCRASH-064.mdに記載する。受領した生のログ・ダンプ・曲情報は配布物に含めない。

Windows実機のGUI、実インストール・更新、連続再生中のネイティブクラッシュの再現、Bilibili・Discordとの実接続は未検証。自動試験はアプリ側の問題のある呼び出しを再現するもので、Windows実機の完全解消を証明するものではない。今回は見た目の変更を行っておらず、UI確認は静的検証と既存の模擬DOM試験。GitHub関連は変更していない。

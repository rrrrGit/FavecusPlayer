# 配布前の確認と限界

## 外部ページと端末内の権限

Bilibiliなどの外部ページは、sandbox・contextIsolationを有効にし、Node機能を公開しない。ファイル操作はアプリ側の限定されたIPCで行い、送信元ウィンドウ・メインフレーム・操作引数を検証する。保存済みメディアは識別トークンで解決し、任意のローカルパスを外部ページへ公開しない。

保存用の通信ではBilibiliの許可したAPIと配信・画像ホストを検証する。CookieはBilibili APIへだけ付け、CDN転送では送らない。転送先も検証し、1ストリーム8GB、通信の無進行60秒、再試行回数などを制限する。保護・試聴フラグのある配信を保存対象にしない。

ZIPの取り込みは相対パス、サイズ、参照、親子の循環を検証する。選択したリストのメディアだけを復元し、途中の失敗では変更を戻す。保存ファイルの整理は新しい配置とindex.jsonの更新後に元データを片付ける。

## 診断と公開ファイル

保存診断へ記録するのは分類コード、処理段階、HTTP/API状態、許可したネイティブコード、曲ID・パート、ジョブと記録のID。Cookie、署名付き配信URL、生の例外文、保存先の実パスを含めない。ログは端末内へ保存し、自動送信しない。2MiBを超えた保存診断は前のログへ退避する。

公開するソース・EXE・操作ガイドへ、ユーザーのプレイリスト、ログインセッション、実ログ、クラッシュダンプ、ダウンロード済みの動画・音声を同梱しない。アプリのDiscord Client IDやGitHubリポジトリ名は秘密の認証情報ではない。

## 実行環境と表示情報

インストーラーは実行環境のサイズ・SHA256と、同梱アプリのマニフェストを検証する。Windowsのアプリ表示は、検証済みランチャーからアイコンとバージョンリソースを移す。Electronのコード、マニフェスト、他のリソースは変更しない。リンク先への書き込みを拒否し、更新途中のファイルを既存本体へ置き換えない。実行ポリシーを変更・無効化しない。

アプリのソースを暗号化・難読化しても、端末で動くコードや埋め込んだ復号鍵を秘密にすることはできない。公開ソースへ認証情報を埋めず、送信先・権限・入力を制限する。パスワードなしの共有ZIPは受け取った人が内容を読める形式であり、秘密保持のための暗号化ではない。

EXEのコード署名、Windows実機でのネイティブ動作、最新のElectronの脆弱性調査は別の確認事項。この文書は完全な安全性を保証するものではない。

# 0.6.6 検証記録

## 確認対象

- 親・子・孫、複数の最上位、選択先の親、空の祖先と選択外の曲の除外。
- 保存済み音声・サムネイルの階層に沿った復元、再起動、無効な保存先と登録失敗時の復元。
- 重なった参照選択、親削除、冗長な最上位参照、親子の順序・検索。
- 指定曲の前・後への追加・移動、同曲の再配置、古い挿入位置の拒否、キャンセル。
- 未完了の容量確認を中止して保存開始、遅延応答の無視、保存中の容量・残り時間、完了済みを除く必要空き容量。
- 取り込みUIの選択と全件ボタン、親検索、検索で隠れた選択、子のチェック解除。
- Google DriveのURL検証、設定保存と配布先の表示。
- 既存の再生・保存・アーカイブ・キー・Discord・インストール処理の回帰検証、Windows PEと模擬起動、画面リソース・操作ガイド。

件数とソースハッシュは配布ソースのrelease-validation/completion.jsonと各ログを参照する。Nodeはtest-isolation=noneで集計する。

## 未確認の範囲

Windows実機のGUI・長時間再生、Bilibili実通信と大量保存、Discord実表示は未確認。従来のクラッシュ対策を維持し、完全解消は断定しない。元の出力に親子関係が残っていない場合は復元できない。未確認の曲が多い間は容量・時間の推計が大きく変わる。追加の再圧縮は行わない。

新しい共有方式とGitHub公開は対象外とし、Google Driveでの配布を継続する。

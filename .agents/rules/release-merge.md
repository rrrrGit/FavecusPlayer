# Release公開後のmain統合・ブランチ削除手順

Release公開後の「`main` への統合」と「統合済みの作業ブランチの削除」は、**ユーザーが指示したときに限り**行う（2026-11-20規則変更）。

1. 作業ブランチの最新をPush済みで、Release（タグ・添付）が公開済みであることを確認する。
2. `main` を最新にして、通常のマージ（`--no-ff`、履歴の書き換えなし）で統合してPushする（強制Pushしない）。
3. `main` に統合済みであることを確認してから、リモートとローカルの作業ブランチを削除する（他のブランチ・タグは削除しない）。
4. リリース作成時に転記した版ごとの変更記録mdがあれば、アーカイブまたは削除する。
5. 統合・削除の前後の状態（コミットSHA）を記録する。
